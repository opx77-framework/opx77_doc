---
title: Client
description: The character contract on the client — a read-only mirror of the local character, and other players' public state.
---

```lua
local character = OPX.Api.Get('character')
```

From client code inside opx_infinity. These read a local mirror of the server; nothing is authoritative. Never yields. The client also puts each player's character name on the platform nameplate above their head.

## GetPlayerData [#client-character-getplayerdata]

The mirrored PlayerData. Read only.

```lua
character.GetPlayerData()
```

**Returns**
- `table` — `{}` before a character loads; see [PlayerData](/docs/opx_infinity/character/player#player)

## HasJob [#client-character-hasjob]

Primary job only.

```lua
character.HasJob(name, onDutyOnly, minGrade)
```

**Parameters**
- name: `string`
- onDutyOnly?: `boolean`
- minGrade?: `integer`

**Returns**
- `boolean`

```lua title="Example"
if character.HasJob('ncpd', true, 2) then print('on duty, grade 2+') end
```

## State bag [#state-bag]

The server writes the public part of each loaded character to that player's state bag. Any client in the same routing bucket can read it, from any resource, with `Open77.state.player(playerId)`; inside opx_infinity use [`GetPlayerState`](#client-character-getplayerstate). Money, metadata, user id, pay and `bankAuth` are never on the bag. Keys are written only when they change, and cleared on logout or character switch. Every key is readable by every client in the bucket.

| Key | Shape |
|---|---|
| `citizenId` | `string` |
| `name` | `string` `"First Last"`, absent until the character is named |
| `charInfo` | `{ firstName?, lastName?, gender?, origin? }` — `origin` is always empty today |
| `job` | `{ name, label, type?, onDuty, isBoss, grade = { name, level } }` |
| `gang` | `{ name, label, onDuty, isBoss, grade = { name, level } }` |
| `username` | `string`, the platform account name |
| `life` | `{ dead, lastStand }` from `metadata.isDead` / `metadata.inLastStand` |

```lua title="Example (any resource)"
local bag = Open77.state.player(playerId)
```
