---
title: Client
description: The character contract on the client — a read-only mirror of the local character, and other players' public state.
---

```lua
local character = OPX.Api.Get('character')
```

From client code inside opx_infinity. These read a local mirror of the server; nothing is authoritative. Never yields. The client **hides** every other player's platform nameplate: no character name and no account gamertag over a stranger's head ([Privacy](/docs/opx_infinity/character#privacy)).

## GetPlayerData [#client-character-getplayerdata]

The mirrored PlayerData. Read only.

```lua
character.GetPlayerData()
```

**Returns**
- `table` — `{}` before a character loads; see [PlayerData](/docs/opx_infinity/character/player#player)

## HasJob [#client-character-hasjob]

Primary job only.

```lua
character.HasJob(name, onDutyOnly, minGrade)
```

**Parameters**
- name: `string`
- onDutyOnly?: `boolean`
- minGrade?: `integer`

**Returns**
- `boolean`

```lua title="Example"
if character.HasJob('ncpd', true, 2) then print('on duty, grade 2+') end
```

## GetPlayerState [#client-character-getplayerstate]


**Parameters**
- playerId: `number`

**Returns**

## GetPlayerIdentity [#client-character-getplayeridentity]

Kept for the old contract: a fresh table of three nils. Staff name tags come from the staff tag list instead ([admin](/docs/opx_infinity/admin)).

```lua

```

**Parameters**
- playerId: `number`

**Returns**
- `{ name = nil, username = nil, citizenId = nil }`

## State bag [#state-bag]

**Empty since PR #93.** A player bag reaches every client in the routing bucket (the whole city), so the character module writes **no key** on it (`State.KEYS = {}`, held by a test). The keys an older build wrote (`citizenId`, `name`, `charInfo`, `job`, `gang`, `username`, `life`) are cleared once per player when they are found.

| Need | Use instead |
|---|---|
| The local player's own character | [`GetPlayerData`](#client-character-getplayerdata) or the [`GetPlayerData` client export](/docs/creators/client/getplayerdata) |
| Another player's job, gang, name or life state | the server: [server exports](/docs/creators/server) such as `GetPlayerData`, `HasJob`, `IsDown`. Never hand a name on to a client that has not met that character. |
| Who is who, for staff | the staff name tags (`opx.admin.self.tags`) |
