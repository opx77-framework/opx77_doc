---
title: Server
description: The inventory contract on the server — give, take, count and check items in bags, stashes and trunks.
---

```lua
local inventory = OPX.Api.Get('inventory')
```

From server code inside opx_infinity.

- A **target** is a player id (their loaded character's bag) or a citizen id (also reaches an offline bag: loaded for the call, then written and released).
- Every function that takes a target, a vehicle or a container **yields**: call it from a thread.
- A `Result` is `{ ok = true, value }` or `{ ok = false, error, detail }`. Codes: [Refusal codes](/docs/opx_infinity/inventory#codes).

```lua title="Example"
CreateThread(function()
    local inventory = OPX.Api.Get('inventory')
    local result = inventory.AddItem(source, 'water', 2)
    if not result.ok then print('refused: ' .. result.error) end
end)
```

## AddItem [#server-inventory-additem]

Adds items. Adds nothing on `no_room` / `too_heavy`. Yields. Audited.

```lua
inventory.AddItem(target, name, count, metadata)
```

**Parameters**
- target: `number|string`
- name: `string`
- count?: `integer` — default 1
- metadata?: `table` — copied onto each unit, max [`MAX_METADATA_BYTES`](/docs/opx_infinity/inventory#config-inventory-max-metadata-bytes) encoded

**Returns**
- `Result` — value `true`

## CountWhere [#server-inventory-countwhere]

Counts stacks whose metadata has every field of `match`. Yields.

```lua
inventory.CountWhere(target, name, match)
```

**Parameters**
- target: `number|string`
- name: `string`


## AddToStash [#server-inventory-addtostash]

Adds to a stash by its storage key, loading it without opening it. **Yields.** Audited `inventory.stashAdd`.

```lua
inventory.AddToStash(name, item, count, metadata, options)
```

**Parameters**
- name: `string`
- item: `string`
- count?: `integer`
- metadata?: `table`
- options?: `table` — `{ creator, cap }` (what the export passes); limits creation
  - A missing stash is created at the configured size (or 50 slots / 100 000 g).
  - With `options`: only configured stashes, or names `<creator>.<name>` while the creator holds fewer than `cap` (default 25, counted in the database); else `stash_namespace` / `stash_cap`.

**Returns**
- `Result` — value `true`

## OpenStash [#server-inventory-openstash]

Opens a stash beside the player's bag and raises their screen. Yields. The caller decides who may open it; this only checks reach, and only when `position` is given.

```lua
inventory.OpenStash(playerId, name, options)
```

**Parameters**
- playerId: `number`
- name: `string`
- options?: `table`
  - `slots`: default 50
  - `maxWeight`: default 100000
  - `label`, `position` (`{ x, y, z }`), `bucket`

**Returns**
- `Result` — value: container id

```lua title="Example"
inventory.OpenStash(source, 'police_evidence', {
    label = 'Evidence', position = { x = 10.0, y = 20.0, z = 7.5 },
})
```

## RegisterUsable [#server-inventory-registerusable]

Sets the function called when the item is used. The last registration wins. Not called for weapons or ammunition.

```lua
inventory.RegisterUsable(name, handler, owner)
```

**Parameters**
- name: `string`
- handler: `function` — `handler(source, info)`
  - `info`: `{ name, slot, count, metadata, label, citizenId }`
  - Must return `{ ok = true, consume? }` or `{ ok = false, error? }` within [`USE_HANDLER_MS`](/docs/opx_infinity/inventory#config-inventory-use-handler-ms). Runs on its own thread and may yield.
  - `consume` overrides `USE.CONSUME`.
- owner?: `string`

**Returns**
- `ok`: `boolean`, `code`: `string?`

```lua title="Example"
inventory.RegisterUsable('lockpick', function(source, info)
    if not nearDoor(source) then return { ok = false, error = 'too_far' } end
    return { ok = true, consume = 0 }
end, 'mymodule')
```

## RegisterItem [#server-inventory-registeritem]

Adds an item to the catalogue at runtime, on the server and every client, or replaces one its own owner registered. Validated whole by `Catalog.Register`, which both halves run; sent to a client that joins later on its hello. Never a weapon or ammunition, never a name config or another owner holds. Not persisted. The [`RegisterItem`](/docs/creators/server/registeritem) export is the door for another resource.

```lua
inventory.RegisterItem(name, definition, owner, cap)
```

**Parameters**
- name: `string`
- definition: `table` — `{ label?, description?, weight?, stack?, drop?, category?, image?, model?, use? }` (lower case)
- owner: `string`
- cap?: `integer` — most items this owner may hold registered (default 64)

**Returns**
- `Result` — the item as `GetItem` reads it; errors `bad_name`, `bad_owner`, `item_taken`, `item_cap`, `bad_definition:<field>`

## HolsterWeapon [#server-inventory-holsterweapon]

Puts away the weapon this module put in the player's hands, reading its rounds back into the bag first. The one way another module may holster somebody; the admin `/opx.admin.weapon.holster` goes through it.

```lua
inventory.HolsterWeapon(playerId)
```

**Parameters**
- playerId: `number`

**Returns**
- `Result` — value `{ name, serial }`; errors `bad_argument`, `not_armed`

```lua title="Example"
local put = inventory.HolsterWeapon(target)
if not put.ok and put.error == 'not_armed' then print('unarmed') end
```
