## Offer [#server-spawn-offer]

Called by `character` on every join. Does not yield. Do not call it for a character already placed.

```lua
spawn.Offer(source, citizenId)
```

**Parameters**
- source: `number`
- citizenId: `string`

**Returns**
- `boolean` — `true`: spawn has taken over placement; `false`: "place them yourself" (see [How a choice runs](/docs/opx_infinity/spawn#flow))

```lua title="Example"
if not spawn.Offer(source, citizenId) then
  -- place the body yourself
end
```
