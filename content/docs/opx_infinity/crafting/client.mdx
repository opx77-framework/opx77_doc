---
title: Client
description: The crafting contract on the client — open and close a bench's menu.
---

```lua
local crafting = OPX.Api.Get('crafting')
```

From client code inside opx_infinity. While open, the menu asks the server for a fresh view every [`REFRESH_MS`](/docs/opx_infinity/crafting#config-crafting-refresh-ms).

## Open [#client-crafting-open]

Asks the server for the bench and opens the menu. The server checks everything again.

```lua
crafting.Open(benchKey)
```

**Parameters**
- benchKey: `string`

**Returns**
- `Result` `true` — errors `invalid_bench`, `no_screen` (no `menu`)

```lua title="Example"
crafting.Open('mymodule:bench')
```

## Close [#client-crafting-close]

Closes the menu.

```lua
crafting.Close()
```

**Returns**
- `Result` `true`

## State [#client-crafting-state]

```lua
crafting.State()
```

**Returns**
- `Result` `{ open, bench }`
