---
title: theme
description: The server's colour scheme and surface style, set in one config file and pushed to every player's interface.
---

Sets the look of every OPX screen: accent colour, alarm colour, panel darkness, scanline, tilt and corner cut. The operator sets them once; every player gets the same theme and cannot pick their own. From one accent hex the module derives the whole colour ladder (idle, deep, hi, text, alarm and two panel grounds). A key left out keeps the interface's shipped value. Without this module the interface keeps its shipped red.

| | |
|---|---|
| Side | both |
| Requires | none |
| Contract | `theme` v1 — [server](/docs/opx_infinity/theme/server) |
| Config | `config/theme.lua` (**server** script) |
| Data | none |

- The config is a server script: clients never hold a copy and only receive the resolved values.
- Bad values are refused at start with a line in the server log, one per value.

## Configuration

`config/theme.lua` sets `OPX.Config.MODULES.theme`.

| Key | Default | Effect |
|---|---|---|
| <a id="config-theme-enabled" />`enabled` | `true` | `false`: the interface keeps its shipped look. |
| <a id="config-theme-accent" />`ACCENT` | `'#ff3b47'` | The main colour, `#RRGGBB` only. Every other rung is derived from it. A very light or very dark accent (lightness outside 0.30–0.78) is accepted with a warning: the bright states will look alike. |
| <a id="config-theme-alarm" />`ALARM` | `'#ffa8ae'` | The alarm colour, `#RRGGBB`. Unset, it is derived from `ACCENT`. |
| <a id="config-theme-plate-opacity" />`PLATE_OPACITY` | `0.78` | Darkness of panel backgrounds, 0.20–0.98. |
| <a id="config-theme-interlace" />`INTERLACE` | `1` | Scanline strength: `0` off, `1` shipped, `2` double; capped at 3. |
| <a id="config-theme-tilt" />`TILT` | `7` | Lean of edge-anchored panels, in degrees, 0–15. |
| <a id="config-theme-cut" />`CUT` | `1` | Scale of the corner cut over 6/12/20 px. Never 0. |
