---
title: Events
description: Network events and public server events of the vehicles module.
---

This module has **no** client → server events. `opx:net:vehicles:spawn` and `opx:net:vehicles:store` were removed (PR #99): no client in opx_infinity sent them, and they brought an owned car out anywhere, or put one away from across the map with passengers inside. Players use a [garage](/docs/opx_infinity/garages) or a [dealer](/docs/opx_infinity/dealership); code uses the [server contract](/docs/opx_infinity/vehicles/server).

## opx:on:vehicles:spawned [#opx-on-vehicles-spawned]

Server, host-wide. An owned car was brought out. Public to every server resource (see [Public server events](/docs/creators/events#vehicles)).

```lua
AddEventHandler('opx:on:vehicles:spawned', function(playerId, data) end)
```

- playerId: `number`
- data: `table`
  - `citizenId`, `plate`, `record`: `string`
  - `vehicleId`: the runtime id
  - `vehicleKey`: `string` — the engine id as text
  - `recalled`: `boolean`

## opx:on:vehicles:stored [#opx-on-vehicles-stored]

Server, host-wide. It was put away, or the host removed it.

```lua
AddEventHandler('opx:on:vehicles:stored', function(playerId, data) end)
```

- playerId?: `number`
- data: `table` — `{ citizenId, plate, garage }`, or `{ citizenId, plate, removed }` (`removed` says why)

## opx:on:vehicles:registered [#opx-on-vehicles-registered]

Server, host-wide. A vehicle row was made for a character (`Register`: a dealer sale, the `AddVehicle` export, a staff give).

```lua
AddEventHandler('opx:on:vehicles:registered', function(playerId, data) end)
```

- playerId?: `number`
- data: `{ citizenId, plate, record, garage }`

## opx:on:vehicles:state [#opx-on-vehicles-state]

Server, host-wide. `SetState` moved a vehicle to stored or impounded.

```lua
AddEventHandler('opx:on:vehicles:state', function(playerId, data) end)
```

- playerId?: `number`
- data: `{ citizenId, plate, state, garage }`
