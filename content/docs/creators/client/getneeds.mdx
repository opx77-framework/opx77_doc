---
title: GetNeeds
description: Reads the local player's needs, as the server last sent them.
---

<a id="export-client-getneeds" />

```lua
local res = exports.opx_infinity:GetNeeds()
```

Sync. Read only: the server owns the needs, and a client script cannot move them. To feed or drain a need, call the server exports [`AddNeeds`](/docs/creators/server/addneeds) / [`SetNeeds`](/docs/creators/server/setneeds) from your resource's server side.

**Returns**
- `{ values, citizenId, ready }`

**Errors**
- `no_character`, `not_loaded`

```lua title="Example"
local res = exports.opx_infinity:GetNeeds()
if res.ok then print(res.value.values.hunger) end
```
