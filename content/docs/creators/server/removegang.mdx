---
title: RemoveGang
description: Removes a gang membership from a character.
---

<a id="export-server-removegang" />

```lua
local res = exports.opx_infinity:RemoveGang(target, name)
```

Scope `write` · must be awaited — a synchronous call answers `export.mustAwait` before touching anything.

**Parameters**
- target: `number | string` — player id or citizen id
- name: `string`

- `target` is a connected player id or a citizen id.
- Goes through the same function as the staff commands; a change raises [`opx:on:character:gang`](/docs/creators/events#opx-on-character-gang) with `removed` naming it.

**Returns**
- `true`

**Errors**
- `gang.notMember`, `character.notFound`, `export.badArgument`, `error.unavailable`

```lua title="Example"
CreateThread(function()
  local pending, why = Open77.exports.call('opx_infinity', 'RemoveGang', citizenId, 'valentinos')
  if not pending then return print('not sent: ' .. tostring(why)) end
  local res = pending:await()
  if not (res and res.ok) then return print('refused: ' .. tostring(res and res.error)) end
  print('removed')
end)
```
