---
title: RemoveDoor
description: Deletes a managed door, ox_doorlock's removeDoor.
---

<a id="export-server-removedoor" />

```lua
local res = exports.opx_infinity:RemoveDoor(ref)
```

Scope `write` · must be awaited — a synchronous call answers `export.mustAwait` before touching anything.

**Parameters**
- ref: `integer | string` — door id or seeded key

- The native door goes back to the game. A door seeded from `DOORS` leaves a tombstone so the next boot does not insert it again.

**Returns**
- nothing (`res.value` is nil)

**Errors**
- `doorlock.unknownDoor`, `doorlock.error.save_failed` (was `doorlock.save_failed` before PR #95), `export.badArgument`, `error.unavailable`

```lua title="Example"
CreateThread(function()
  local pending = Open77.exports.call('opx_infinity', 'RemoveDoor', 12)
  local res = pending and pending:await()
  if not (res and res.ok) then print('refused: ' .. tostring(res and res.error)) end
end)
```
