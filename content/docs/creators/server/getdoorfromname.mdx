---
title: GetDoorFromName
description: A managed door by its name, ox_doorlock's getDoorFromName.
---

<a id="export-server-getdoorfromname" />

```lua
local res = exports.opx_infinity:GetDoorFromName(name)
```

Scope `read` · sync.

**Parameters**
- name: `string` — 1–64 characters, exact

- Several doors may share a name: the lowest id wins.

**Returns**
- the door, as [`GetDoor`](/docs/creators/server/getdoor)

**Errors**
- `doorlock.unknownDoor`, `export.badArgument`, `error.unavailable`

```lua title="Example"
local res = exports.opx_infinity:GetDoorFromName('NCPD front desk')
if res.ok then print('door #' .. res.value.id) end
```
