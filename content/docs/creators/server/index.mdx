---
title: Server exports
description: What a server script of another resource can call on opx_infinity — players, money, jobs, metadata, needs, items, stashes, chat, vehicles, doors, toasts, bars and crafting benches.
---

Defined in `core/server/exports.lua`. Read [For creators](/docs/creators) first: every export answers `{ ok, value | error }`, the operator decides who may call it, and writes must be **awaited**.

## Scope and await

| Label | Meaning |
|---|---|
| Scope `read` | Allowed by [`SERVER.EXPORTS.READ`](/docs/opx_infinity/core/config#config-server-exports) (`'*'` by default). |
| Scope `write` | Allowed by [`SERVER.EXPORTS.WRITERS`](/docs/opx_infinity/core/config#config-server-exports) (nobody by default). Audited with your resource name. |
| sync | Answers at once; `exports.opx_infinity:Name(...)` is fine. |
| must be awaited | Can wait on the database. Call it with `Open77.exports.call(...)` and `:await()`; a synchronous call answers `export.mustAwait`. |
| await it | A write that answers from memory today. Use the promise form anyway. |

## Common arguments

| Name | Accepts |
|---|---|
| `source` | a connected player id (number) |
| `citizenId` | a citizen id string |
| `target` | a connected player id **or** a citizen id (a citizen id reaches an offline bag and must be awaited) |
| `metadata` | `nil` or a plain table |

- [`GetMetadata`](/docs/creators/server/getmetadata) — read · sync (must be awaited for a citizen id)
- [`SetMetadata`](/docs/creators/server/setmetadata) — write · sync (must be awaited for a citizen id)

## When your resource stops [#stop]

Your use handlers, crafting benches and server-started bars go with it. The cleanup runs only if your resource is still not `running` or `starting` when the stop reaches `opx_infinity` (a stop arrives on a later tick): on a `restart` your new instance has usually registered again already, and its registrations replace the old ones rather than being wiped. Register on every start. Your runtime items stay in the catalogue (stacks of them are in bags), and everything you wrote stays written.

## Doors [#doors]

ox_doorlock's server exports under their ox meaning (see [doorlock](/docs/opx_infinity/doorlock)). A door is its integer id, or the key a seeded or carried-over door had. No answer ever carries a door's code.

- [`GetDoor`](/docs/creators/server/getdoor), [`GetDoorFromName`](/docs/creators/server/getdoorfromname), [`GetAllDoors`](/docs/creators/server/getalldoors) — read · sync
- [`SetDoorState`](/docs/creators/server/setdoorstate), [`SetDoorLocked`](/docs/creators/server/setdoorlocked), [`CreateDoor`](/docs/creators/server/createdoor), [`EditDoor`](/docs/creators/server/editdoor), [`RemoveDoor`](/docs/creators/server/removedoor) — write · must be awaited

## Examples [#examples]

### Pay a player for a job step [#example-pay]

```lua title="my_jobs/server/main.lua"
-- needs `my_jobs = true` in SERVER.EXPORTS.WRITERS
RegisterNetEvent('my_jobs:delivered', function()
	local playerId = source
	CreateThread(function()
		-- re-check on the server that the delivery really happened, then:
		local pending, why = Open77.exports.call('opx_infinity', 'AddMoney',
			playerId, 'EDDIES', 350, 'delivery')
		if not pending then return print('not sent: ' .. tostring(why)) end
		local answer, failure = pending:await()
		if answer == nil then return print('call failed: ' .. tostring(failure)) end
		if answer.ok ~= true then return print('refused: ' .. tostring(answer.error)) end
		print(('paid, balance is now %d'):format(answer.value))
	end)
end)
```

### Check a job before letting someone in [#example-job]

```lua
-- a read: the synchronous form is fine
local answer = exports.opx_infinity:HasJob(playerId, 'police', true, 2)
if answer.ok and answer.value then
	-- on-duty police, grade 2 or more
end
```

### Restock a shop's back room [#example-stash]

```lua
-- creates `my_shop.backroom` on first use (needs my_shop in WRITERS)
CreateThread(function()
	local pending = Open77.exports.call('opx_infinity', 'AddToStash',
		'my_shop.backroom', 'water', 24)
	local answer = pending and pending:await()
	if not (answer and answer.ok) then
		print('restock refused: ' .. tostring(answer and answer.error))
	end
end)
```
