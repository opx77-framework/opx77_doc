---
title: GetAllDoors
description: Every managed door, ox_doorlock's getAllDoors.
---

<a id="export-server-getalldoors" />

```lua
local res = exports.opx_infinity:GetAllDoors()
```

Scope `read` · sync.

**Returns**
- the doors, as [`GetDoor`](/docs/creators/server/getdoor), sorted by id

**Errors**
- `error.unavailable`

```lua title="Example"
local res = exports.opx_infinity:GetAllDoors()
if res.ok then
  for _, door in ipairs(res.value) do print(door.id, door.name, door.state) end
end
```
