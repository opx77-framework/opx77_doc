title: Lib.Array
description: List helpers — filter, map, find, fold, sort, group and edit in place.
---

Pure. No permission. Every function answers a new table unless it says **in place**.

## Lib.Array.Filter [#lib-array-filter]

The entries a test keeps, in order.

```lua
Lib.Array.Filter(list, test)
```

**Parameters**
- list: `table`
- test: `function(value, index): boolean`

**Returns**
- `table`

```lua title="Example"
local armed = Lib.Array.Filter(rows, function(row) return row.armed end)
```

## Lib.Array.Fold [#lib-array-fold]

Folds the list into one value.

```lua
Lib.Array.Fold(list, step, initial)
```

**Parameters**
- list: `table`
- step: `function(carried, value, index): any`
- initial: `any`

**Returns**
- `any`

```lua title="Example"
local total = Lib.Array.Fold(items, function(sum, item) return sum + item.price end, 0)
```
