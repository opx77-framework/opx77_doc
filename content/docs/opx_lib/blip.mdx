Permission `ui.vanilla.map`.

## Lib.Blip.Place [#lib-blip-place]

Creates a blip at a world position.

```lua
Lib.Blip.Place(position, options)
```

**Parameters**
- position: `{ x, y, z }`
- options?: `table` — `sprite`, `label`, `icon`, `active`, `visibleThroughWalls`, `routable`, `range`

**Returns**
- `Result` — the handle; errors `invalid_position`, `invalid_options`

```lua title="Example"
local pin = Lib.Blip.Place({ x = -1442.2, y = 127.4, z = 18.0 }, { label = 'Night market', routable = true })
```

## Lib.Blip.Follow [#lib-blip-follow]

Creates a blip that follows an entity.

```lua
Lib.Blip.Follow(entity, options)
```

**Parameters**
- entity: `number`
- options?: `table`

**Returns**
- `Result` — the handle; errors `invalid_entity`, `invalid_options`

## Lib.Blip.Move [#lib-blip-move]

**Parameters**

**Returns**
- `Result` — errors `invalid_handle`, `invalid_patch`
